# 🧹 GiupViecNhanh - Nền tảng đặt lịch dịch vụ

Dự án Website ứng dụng mô hình MVC tự xây dựng (Custom MVC) bằng PHP, kết hợp với Tailwind CSS để cung cấp giao diện hiện đại và trải nghiệm tìm kiếm nhân viên mượt mà.

## 🚀 Công nghệ sử dụng
* **Backend:** PHP (Mô hình MVC)
* **Frontend:** HTML5, Tailwind CSS
* **Database:** MySQL
* **Môi trường:** XAMPP (Apache)

## 💡 Tính năng nổi bật
* **Hệ thống tìm kiếm thông minh:** Lọc nhân sự theo từ khóa, kỹ năng và giới tính trực tiếp trên giao diện.
* **Xử lý hình ảnh dự phòng (Smart Avatar):** Tự động hiển thị ảnh placeholder phù hợp nếu dữ liệu hình ảnh gốc bị thiếu.
* **Quy trình đặt lịch:** Trải nghiệm chọn nhân viên và đặt dịch vụ nhanh chóng.
* **Xác thực người dùng:** Hệ thống đăng nhập/đăng ký với bảo mật Session.
